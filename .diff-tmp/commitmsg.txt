fix(updater): map GitHub release asset name in update.json URLs

- gh release upload rewrites spaces in asset filenames to dots, so the URL stored in update.json must use the dotted form (MCP.Switch_0.10.1_x64-setup.exe) instead of the percent-encoded space (MCP%20Switch_0.10.1_x64-setup.exe) that encodeURIComponent produced.
- Introduce githubAssetName() helper that maps the local bundle filename to its GitHub asset name, and reuse it in the manifest URL.

Without this, downloadAndInstall() would request a 404 (verified against the published v0.10.1 release: percent-encoded URL returns 404, dotted URL returns 200).
